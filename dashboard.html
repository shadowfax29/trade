          MT5 setup

          Connect a desktop MT5 account

          The dashboard reads your locally installed MT5 terminal over a local IPC connection. The hosted page cannot see the terminal on its own, so the bridge must run on the same Windows PC that has MT5 open and logged in.

          1. Install the desktop MT5 from your broker and log in. Use a demo account first if you are testing. Web or mobile MT5 does not expose this history API.
          2. Download the history. In MT5, open the Account History tab, right-click inside it, choose Custom period…, pick the date range you want, and press OK. Scroll the list or refresh until the deals appear.
          3. Install Python and the package. On the same PC as MT5, use 64-bit Python and run py -3.11 -m pip install MetaTrader5 pandas flask.
          4. Keep MT5 open while reading. Start the local bridge from the project folder: py -3.11 app.py, then open http://127.0.0.1:5000. It attaches to the running terminal automatically and never asks for your password.
          5. Switch account safely. If you want to read a different account, click Switch account and enter the account login, investor password, and the broker server name exactly as it appears in the MT5 login dialog, then click Run analysis.
          6. Use read-only credentials. The investor password cannot place, modify or close trades. The app does not call any order function and does not store the password. Never use or share your master password for this.
          7. If the report is empty. Check that MT5 is open and logged in, the server string matches exactly, the history range has been downloaded, Python is 64-bit, and py -3.11 -c "import MetaTrader5 as mt5; print(mt5.initialize())" prints True.
          8. On the hosted Vercel site. Click Connect local MT5 only after the local bridge is running and MT5 is open. If the browser blocks it, open http://127.0.0.1:5000 instead and use the same dashboard locally.
          Passwords are never uploaded. Trading Edge analyzer sends account and history requests to your local MT5 terminal. The Vercel deployment is only the interface and guide; it cannot fetch a client account by itself.
